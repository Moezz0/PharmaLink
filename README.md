# PharmaLink – Pharmacy Locator System

Requirements-analysis and project-planning case study for a mobile app that lets patients find which nearby pharmacies have a medicine in stock. Made for the Software Engineering course at Assiut University (Faculty of Computers and Information). The app itself was **not built**; this repository holds the analysis and planning documents.

## What the system would do
- Search medicine availability in real time across registered pharmacies
- Show pharmacy locations and stock levels on a map, with directions and contact
- Register and verify pharmacies
- Live chat with a pharmacist
- Arabic (RTL) and English (LTR) interface

## Planned stack
Flutter (Android and iOS), Node.js with Firebase or Supabase, Google Maps API.
